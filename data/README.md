# data/

Written by the pipeline (not tracked in git):

- `counts.csv`: gene x sample count matrix (step 00A)
- `gene_annotation.csv`: gene identifier to symbol table from the GEO matrix (step 00A)
- `coldata.tsv`: sample annotation built from the GEO series matrix (step 00B)

Raw downloads go to `data_raw/`, analysis outputs to `results/`.

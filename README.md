# Bulk RNA-seq analysis of neoadjuvant chemotherapy response in breast cancer (GSE192341)

[![example-pipeline](https://github.com/bioinfosourabh/bulk-rna-seq/actions/workflows/example-pipeline.yml/badge.svg)](https://github.com/bioinfosourabh/bulk-rna-seq/actions/workflows/example-pipeline.yml)

An R workflow for bulk RNA-seq differential expression between pre-treatment breast tumours that reached pathological complete response (pCR) after neoadjuvant chemotherapy and tumours with residual disease (No pCR). It covers count-matrix and metadata construction from GEO, input validation, DESeq2 with apeglm log2 fold-change shrinkage, sample-level QC, xCell cell-type enrichment, and over-representation (ORA) and gene set enrichment (GSEA) analysis with MSigDB Hallmark, GO Biological Process and Reactome gene sets.

## Dataset

- **GEO accession:** [GSE192341](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE192341)
- **Material:** pre-treatment human breast tumour biopsies
- **Endpoint:** pCR vs residual disease (No pCR) after neoadjuvant chemotherapy
- **Samples:** 87 (pCR = 24, No pCR = 61, response not recorded = 2; the last two are excluded)
- **Input used:** the GEO supplementary processed count matrix and the series-matrix sample annotation

## Installation

R (>= 4.3) is required. From the repository root:

```sh
Rscript install_packages.R
```

This installs only the missing packages: DESeq2, apeglm, GEOquery, AnnotationDbi, org.Hs.eg.db, GO.db, clusterProfiler, DOSE, enrichplot, ReactomePA, reactome.db, GSVA and GSEABase from Bioconductor; tidyverse, data.table, R.utils, pheatmap, ggrepel, patchwork, viridis, hexbin, msigdbr, yaml and rmarkdown from CRAN; and xCell from GitHub ([dviraran/xCell](https://github.com/dviraran/xCell)). Rendering the HTML report (step 06) also needs [pandoc](https://pandoc.org), which ships with RStudio. msigdbr downloads the MSigDB gene sets on first use.

## Usage

**Example run (simulated data, about 3 minutes):**

```sh
Rscript run_pipeline.R --config example/config.yaml
```

The example dataset in `example/data_raw/` contains simulated negative-binomial counts for 11,980 human genes in 18 samples (7 pCR, 10 No pCR, 1 without a response label), generated by `example/simulate_example_data.R`. It is not patient data; it exists to test the code end-to-end and is run by GitHub Actions on every push. Results are written to `example/results/`.

**GSE192341:**

```sh
Rscript run_pipeline.R --download     # step 00 (GEO download) followed by steps 00A-07 and the report
```

or step by step:

```sh
Rscript scripts/00_download_data.R
Rscript scripts/00A_make_counts_from_processed_matrix.R
Rscript scripts/00B_make_coldata_from_GEO.R
Rscript scripts/01_input_validation.R
Rscript scripts/02_deseq2_analysis.R
Rscript scripts/03_qc_vst_pca_distances.R
Rscript scripts/04_deconvolution_xcell.R
Rscript scripts/05_enrichment_ORA_GSEA.R
Rscript scripts/07_visualizations.R
Rscript scripts/06_render_report.R
```

`run_pipeline.R --from 02 --to 05` runs a subset of steps. The run needs about 8 GB of RAM; enrichment (GO and Reactome GSEA) takes most of the run time.

## Workflow

### 00. Download (`00_download_data.R`)

Downloads the GSE192341 series matrix with `GEOquery::getGEO()` and exports the sample annotation (`pData`) to `data_raw/GSE192341_pdata.tsv`. Downloads the supplementary files with `getGEOSuppFiles()`, selects the processed count matrix (regular expression `geo$processed_file_regex`) and writes it to `data_raw/GSE192341_processed_data.txt`. File sizes and MD5 checksums are recorded in `data_raw/download_manifest.tsv`.

### 00A. Count matrix (`00A_make_counts_from_processed_matrix.R`)

Parses the processed matrix: the first column is the gene identifier, further non-numeric columns are annotation (the second is taken as the gene symbol), and numeric columns are samples. Ensembl version suffixes are removed and rows that then share an identifier are summed. The script stops on missing or negative values and on matrices that look like normalised expression (non-integer values with small column sums); non-integer expected counts are rounded.
Output: `data/counts.csv`, `data/gene_annotation.csv`, `results/rds/counts_raw.rds`.

### 00B. Sample annotation (`00B_make_coldata_from_GEO.R`)

Builds `coldata` from the GEO annotation: the response field (set in `metadata$response_column`, or detected as the first `:ch1` field containing "pcr" or "response") is mapped to `condition` with levels `No_pCR` (reference) and `pCR` using the value lists in the configuration; unmapped values become missing. ER, PR and HER2 status are carried over when present. The mapping table is printed so that it can be checked.
Output: `data/coldata.tsv`, `results/rds/coldata.rds`.

### 01. Input validation and gene filtering (`01_input_validation.R`)

Count-matrix columns are matched to the coldata column with the largest overlap (GSM accession, title or another identifier) and renamed to GSM accessions; samples present in only one table are reported and dropped, and order is checked with `identical()`. Samples without a response label are removed. Per-sample library size, number of detected genes and the share of reads in the 100 most abundant genes are recorded. Genes are kept if they have at least 10 reads in at least *n* samples, where *n* is the size of the smaller group (the rule suggested in the DESeq2 vignette; configurable).
Output: `results/rds/counts_filtered.rds`, `results/rds/coldata_validated.rds`, `results/tables/sample_qc_metrics.tsv`, `results/tables/gene_filtering_summary.tsv`.

![Sample QC metrics](Visualizations/Fig01_Sample_QC.png)

### 02. Differential expression (`02_deseq2_analysis.R`)

- Model: negative binomial GLM, design `~ condition` (DESeq2)
- Normalisation: median-of-ratios size factors
- Dispersion: gene-wise estimates shrunk towards the fitted mean-dispersion trend
- Test: Wald test for `condition_pCR_vs_No_pCR`; Benjamini-Hochberg adjusted p-values (`alpha = 0.05`, independent filtering)
- Effect sizes: log2 fold changes shrunk with apeglm (`lfcShrink(type = "apeglm")`); the unshrunken MLE estimate is kept in `log2FoldChange_MLE`

Positive log2 fold changes mean higher expression in pCR. `DESeq2_results_all.tsv` holds every tested gene (sorted by adjusted p-value); `DESeq2_results_significant.tsv` holds genes with padj < 0.05.
Output: `results/rds/dds.rds`, `results/tables/DESeq2_results_all.tsv`, `DESeq2_results_significant.tsv`, `DESeq2_run_summary.tsv`, `normalized_counts.tsv`, `vst_matrix.tsv`.

### 03. Sample-level QC (`03_qc_vst_pca_distances.R`)

A blind variance-stabilising transformation (VST) is computed. PCA uses the 500 most variable genes, as in `DESeq2::plotPCA()`. Euclidean distances and Pearson correlations between samples use all filtered genes. A sample is flagged as a potential outlier when the z-score of its mean distance to all other samples exceeds 3 in absolute value; flagged samples are reported, not removed.
Output: `results/rds/vsd.rds`, `results/tables/qc_pca_coordinates.tsv`, `qc_pca_variance_explained.tsv`, `qc_sample_distance_matrix.tsv`, `qc_sample_correlation_matrix.tsv`, `qc_outlier_flags.tsv`, `qc_top_variable_genes.tsv`.

### 04. Cell-type enrichment with xCell (`04_deconvolution_xcell.R`)

xCell (Aran et al. 2017) scores 64 immune and stromal cell types, plus ImmuneScore, StromaScore and MicroenvironmentScore, from VST expression with genes labelled by HGNC symbol. Where several genes share a symbol, the row with the highest mean expression is kept. Groups are compared per cell type with a two-sided Wilcoxon rank-sum test and Benjamini-Hochberg correction. The scores are relative enrichment scores, not cell proportions (see [Notes](#notes-and-limitations)).
Output: `results/tables/deconvolution_xcell_scores.tsv`, `results/tables/deconvolution_xcell_pcr_vs_nopcr.tsv`, `results/rds/xcell_scores.rds`.

### 05. Pathway enrichment (`05_enrichment_ORA_GSEA.R`)

Gene identifiers are mapped to Entrez IDs with org.Hs.eg.db (one ID per gene).

- **ORA:** genes with padj < 0.05, split into higher and lower in pCR, are tested against the universe of genes with a non-missing adjusted p-value. Tests are hypergeometric with BH correction (`enricher`, `enrichGO`, `ReactomePA::enrichPathway`).
- **GSEA:** all tested genes are ranked by the DESeq2 Wald statistic (configurable: shrunken log2FC) and analysed with `GSEA`, `gseGO` and `ReactomePA::gsePathway` (fgsea, `eps = 0`, fixed seed).
- **Gene sets:** MSigDB Hallmark (msigdbr), GO Biological Process, Reactome; gene-set size 10-500.

Output: `results/tables/DESeq2_results_annotated.tsv`, `enrich_{hallmark,GO_BP,reactome}_{ORA_UP,ORA_DOWN,GSEA}.tsv`, `enrichment_summary.tsv`, `results/rds/enrichment_results.rds`.

## Results for GSE192341

These figures come from an earlier run of this workflow. The plotting code is the same as `scripts/07_visualizations.R`. Steps 00A-06 have since been revised (sample matching, a group-size-based gene filter, explicit Entrez mapping), so a fresh run can give slightly different numbers.

- **Samples:** 85 tumours analysed (61 No pCR, 24 pCR).
- **Differential expression:** 22,425 genes had an adjusted p-value. Of these, 4,108 had padj < 0.05: 1,610 higher in pCR (266 with |log2FC| > 1) and 2,498 lower in pCR (658 with |log2FC| > 1).
- **Pathways:** pre-ranked GSEA and ORA agree on the main pathways.
  - Higher in pCR: proliferation-related Hallmark sets (E2F targets, G2M checkpoint, MYC targets V1/V2, mitotic spindle) and immune-related sets (interferon-gamma and interferon-alpha response, allograft rejection, inflammatory response, IL6-JAK-STAT3 signalling).
  - Higher in No pCR: oestrogen response (early and late), myogenesis, bile acid metabolism and peroxisome.
- **Interpretation:** this pattern is consistent with the established association of high proliferation, ER-negative status and immune infiltration with response to neoadjuvant chemotherapy. Because receptor status is not part of the design, part of the signal may reflect differences in ER status between the groups.

## Notes and limitations

- **Design:** the model contains response only. ER, PR and HER2 status are kept in `coldata` and can be added to `design$formula` (for example `~ er_status + condition`) to separate response-associated expression from subtype effects.
- **xCell input:** xCell was developed on gene-length-normalised expression (TPM/FPKM). Here it is applied to VST counts. Because ssGSEA is rank-based within each sample, this gives the same ranks as normalised counts, but longer genes rank higher than they would in TPM. Scores should therefore be compared between samples, not read as cell fractions.
- **Outliers:** outliers are flagged for inspection and not removed automatically.
- **Thresholds:** the volcano plot uses |log2FC| > 0.5 for display only; significance is defined by padj < 0.05.
